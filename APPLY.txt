xDBML -- 0.6.4: the parser agrees with every case of the grammar test corpus
Base: origin/main 33c3bed (release 0.6.3).

A reader reported two cases of grammar/test-cases.md that the parser
contradicts. Running every case against the 0.6.3 parser found thirteen:
four parser gaps and nine defective cases. This package fixes all of them,
makes the parser's test suite run every case, sets the release date, and
ends with the release.

WHAT CHANGED
------------
parser\src\parser.ts
  Import item lists are list bodies (spec 3.9, 27.2): one item per line,
  commas and semicolons optional. They required a comma between items.
  use / reuse in a document declaring xdbml: 0.1 is a parse error (the
  module system belongs to v0.2, Appendix D item 3).
  SUPPORTED_XDBML_VERSION 0.6.4.
parser\src\name-resolver.ts
  invalid-tuple-positions: positions not running from [0] without a gap,
  each once (8.6). named-type-shadows-builtin: a Type named like a
  built-in type, in any letter case (15.2). Both errors from v0.6,
  warnings in a document declaring an earlier version.
parser\test\run-tests.ts
  New group "v0.6.4 grammar test corpus": every case of
  grammar\test-cases.md, imports resolved against grammar\fixtures\.
  Four targeted checks. Type Money in two older tests becomes Type Amount;
  the version-refusal tests use 0.6.5 and 0.6.99. 433 tests (298 before).
grammar\test-cases.md, grammar\fixtures\ (NEW: catalog, auth, billing,
internal-helpers, other)
  Ref cases and the polyglot case declare their entities; module cases
  read the fixtures; the import equivalence case splits in two (same
  headings and anchors kept); tuple and built-in cases declare 0.6, each
  with a 0.5 twin expecting the warning; the newer-patch case declares
  0.6.99. The introduction and "Test runner" describe the real runner.
examples\06-financial-services.xdbml, parser\test\examples\ (same file),
renderer\test\goldens\06-financial-services.svg
  Type Money becomes Type MonetaryAmount: its four Money fields had the
  built-in money type all along. The golden differs only in those four
  type labels.
spec\v0.6.md
  3.9 lists import item lists among the list bodies; 27.2 says so; 8.6
  and 15.2 state the severities; What's new gains a v0.6.4 sentence.
public\llms.txt, mcp\src\reference.ts (regenerated)
  A Common mistake for Type Money, and the rule in Fields.
playground\help\diagnostics-panel.md
  The two new codes and their severities.
CHANGELOG.md
  v0.6.4 section, released 2026-10-02; v0.6.3 superseded.
