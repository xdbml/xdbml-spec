xDBML -- 0.6.3, delta 3: renderer, playground and example 16 (diagram views)
Base: 0.6.3 delta 2 (grammar and parser), committed on top of ce1294f.

The renderer draws a diagram view and the playground switches to one from a
Diagram menu. After this delta the pushed site, playground and spec agree,
so main may be pushed. The rendering API and MCP server keep the published
0.6.2 packages until the 0.6.3 release; delta 4 adds their parameters.

WHAT CHANGED
------------
renderer\src\layout\layout.ts
  buildDiagram(doc, collapsedPaths, { diagramView }). Field markers are
  computed from every relationship first, then entities are narrowed to the
  members and stacked again in their Containers' columns (restackColumns);
  a Container with no member is not drawn; Refs and Edges are kept when
  both ends are members; supertype groups are computed on the members.
  Every id stays the id it has in the full diagram, so ref:<n> still maps
  to the same declaration for the inspector. An undeclared name draws the
  full diagram.
renderer\src\index.ts
  renderToSVG option diagramView; BuildOptions exported.
renderer\src\interactive\mount.ts
  Option diagramView; handle methods getDiagramView() and
  setDiagramView(name, layout). An empty positions map arranges afresh.
renderer\README.md
  The option and the two handle methods.
renderer\test\run-tests.ts, run-interactive-tests.ts
  11 layout checks and 5 jsdom checks for diagram views.
renderer\test\goldens\16-diagram-views.svg  (NEW)
  Golden of the new example (full diagram).
playground\src\components\diagram\DiagramCanvas.vue
  Diagram menu at the left end of the diagram toolbar, shown when the
  document declares diagram views: Main ERD, then each diagram view.
  Positions, Edge offsets, zoom, Display options and undo history belong
  to the diagram on display (stored under <doc key>#view:<name>); Main ERD
  keeps the keys it had. Collapsed rows are shared. A diagram view opened
  for the first time is arranged (Relational) and fitted. A reload returns
  to the diagram view on display; opening another document starts on Main
  ERD; renaming or removing the diagram view on display returns to Main
  ERD. A new diagram view starts with the default Display options.
playground\test\run-tests.ts
  Two checks on example 16: members, frames and relationships of
  order_to_cash; arranged members stay inside their frames in all three.
playground\help\diagram-views.md  (NEW), help-menu.toml
  New page under "Reading the diagram", after Supertype groups.
playground\help\diagram-pane.md, diagnostics-panel.md,
when-parsing-fails.md, persistence-and-undo.md
  The Diagram menu, the new diagnostics, the parse errors, what is stored.
examples\16-diagram-views.xdbml  (NEW), scripts\examples-manifest.mjs,
examples\README.md
  Example 16: order-to-cash model, four Containers, a database view, a
  supertype group, a sticky note, three diagram views. README table row
  regenerated by prepare-examples.
spec\v0.6.md
  A View in playground button on the 18.2 snippet with the supertype
  group (it declares its own model). The 18.1 snippet declares none of the
  entities it names, so it has no button.
