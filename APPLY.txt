xDBML -- 0.6.2 release: finish steps 3 to 5 by hand, and make release.cmd retry installs
Base: the failed run of tools\release.cmd 0.6.2. Steps 1 and 2 published
@xdbml/parse 0.6.2 and @xdbml/render 0.6.2; both are live on npm, in the
full and in the abbreviated metadata. Step 3 had already set the mcp
dependencies and version before npm install failed, so it resumes at the
install. Do not rerun release.cmd: step 1 would fail with "cannot publish
over the previously published versions".

WHAT CHANGED
------------
tools\release.cmd
  Steps 2, 3 and 4 run npm install with --prefer-online and retry it every
  10 seconds, up to 18 times, before failing. npm view (the wait loops)
  reads the full metadata of a package; npm install reads the abbreviated
  metadata, which can lag behind for a few minutes after a publish and
  fail with ETARGET, as it did here.

FILES
-----
  tools\release.cmd   (EDIT)

APPLY (cmd.exe)
---------------
Unzip, open cmd.exe in the unzipped folder, then:

set REPO=C:\Repos\Hackolade\xdbml-spec
set DELTA=%CD%

REM --- step 3: MCP server --------------------------------------------------
cd /d %REPO%\mcp
npm install --include=dev --prefer-online
npm run check:reference
npm run type-check
npm test
npx wrangler deploy

REM --- step 4: rendering API -----------------------------------------------
cd /d %REPO%\api
npm pkg set dependencies.@xdbml/render=0.6.2
npm install --include=dev --prefer-online
npm run type-check
npx wrangler deploy

REM --- step 5: verify ------------------------------------------------------
cd /d %REPO%
npm view @xdbml/parse dist-tags --prefer-online
npm view @xdbml/render dist-tags --prefer-online
npm view @xdbml/render dependencies --prefer-online

REM --- the script fix, then commit and tag ---------------------------------
copy /Y "%DELTA%\tools\release.cmd" "%REPO%\tools\release.cmd"
git add -A
git commit -m "release 0.6.2; release.cmd retries npm install after a publish"
git push
tools\github-release.cmd 0.6.2

If npm install in step 3 still reports ETARGET, wait a minute and repeat
the same line; npm cache verify clears a stale local copy if it persists.
