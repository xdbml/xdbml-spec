APPLY (cmd.exe)
---------------
Unzip, open cmd.exe in the unzipped folder, then:

set REPO=C:\Repos\Hackolade\xdbml-spec
set DELTA=%CD%
copy /Y "%DELTA%\public\llms.txt" "%REPO%\public\llms.txt"
copy /Y "%DELTA%\mcp\src\reference.ts" "%REPO%\mcp\src\reference.ts"
copy /Y "%DELTA%\mcp\test\run-tests.ts" "%REPO%\mcp\test\run-tests.ts"
copy /Y "%DELTA%\playground\help\relationships-crows-foot.md" "%REPO%\playground\help\relationships-crows-foot.md"
cd /d %REPO%\mcp
call npm run check:reference
call npm test
cd /d %REPO%
git add -A
git commit -m "0.6.2, delta 2 of 2: llms.txt rewritten from the spec, every example checked"
git push

The push publishes llms.txt on xdbml.org. Then release, which publishes the
parser and renderer and redeploys the MCP server with the new reference:
