xDBML -- v0.5 Delta 4: parser and grammar for supertype groups
Base: Deltas 1-3 applied and committed locally on top of origin/main fb985b1.

WHY
---
First implementation phase of v0.5: the parser reads SupertypeGroup and
reports every rule of spec 12.8. The playground runs the parser from repo
source, so after this delta a v0.5 document with groups parses in
docs:dev, its diagnostics appear in the panel with squiggles, and the
diagram shows the entities. The group symbol arrives with Delta 5.

WHAT THIS ADDS
--------------
Parser (parser\src)
  ast.ts            SupertypeGroupDeclaration and SupertypeGroupMember
                    (each member keeps its own settings); element-type note.
  parser.ts         SupertypeGroup dispatch and parseSupertypeGroup():
                    name required (message points at undefinedGroupN),
                    members separated by newline, comma or semicolon,
                    case-insensitive keyword. `supertypegroup` added to the
                    import element types. ParseError gains an optional
                    `code`; a declared version above SUPPORTED_XDBML_VERSION
                    (0.5) is refused with code `unsupported-version`
                    (spec 4.1). compareVersions() treats 0.10 as newer
                    than 0.5.
  supertypes.ts     NEW. Value/alias table and canonicalization, member
                    resolution (bare or container-qualified; ambiguous and
                    non-entity cases get their own message), supertype
                    chains, and checkSupertypeGroups() with the 12.8 rules.
  name-resolver.ts  resolveNames() runs the group checks as pass 4 on the
                    flattened document; new diagnostic codes in the union.
  module-resolver.ts  selective import and aliasing of `supertypegroup`.
  keywords.ts       'supertypegroup' in DECLARATION_KEYWORDS (Monaco
                    highlighting in the playground follows).
  index.ts          exports: supertypeGroupSettings, subtypeStrategy,
                    canonicalSupertypeGroupValue, SUPERTYPE_GROUP_VALUES,
                    resolveSupertypeGroups, supertypeChains,
                    checkSupertypeGroups, SUPPORTED_XDBML_VERSION,
                    compareVersions, and the related types.
  Comments citing chapters 12-30 renumbered by topic, not by +1: several
  already cited an older numbering (Named Type as 13, View as 12, Records
  as 24, path syntax as 18) and now name the right chapter. References
  pinned to a version ("v0.2 §26", "v0.3 §26.14") are unchanged.

New diagnostic codes
  errors:   missing-supertype, unresolved-supertype-group-member,
            invalid-supertype-group-value, duplicate-subtype,
            supertype-is-subtype, subtype-in-multiple-groups,
            supertype-cycle, supertype-attribute-redeclared,
            discriminator-on-overlapping-group
  warnings: empty-supertype-group, merge-without-roll-up
  reused:   duplicate-declaration (group names),
            construct-requires-version (group in a < 0.5 document)

Tests (parser\test\run-tests.ts): 24 new cases, 207 in total.

Grammar
  xDBML.g4          supertypeGroupDefinition, its settings and member
                    rules, SUPERTYPE_GROUP and SEMICOLON tokens, added to
                    topLevelStatement and cloneContent.
  test-cases.md     "§12 SupertypeGroup (v0.5)": five VALID and five
                    INVALID cases. Nothing runs this file automatically;
                    all ten were checked against the parser here.

Spec (spec\v0.5.md)
  3.9 table: "TableGroup, SupertypeGroup | members | newline, comma or
  semicolon". 12.1 reworded to match.

CHANGELOG.md: Added > Tooling (parser, checks, exports, grammar);
Changed > Spec (3.9 / 12.1); Changed > Tooling (version refusal, comment
renumbering).
