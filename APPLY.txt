xDBML -- 0.6.1, delta 3 of 5: renderer test and playground
Base: delta 2 (0.6.1, delta 2 of 5: grammar and parser). Apply delta 2 first.

WHAT CHANGED
------------
renderer\test\run-tests.ts
  The renderer needs no code change: it reads only the FieldDeclaration
  items of entities and Views. A new test checks that fields named `note`
  and `records` draw rows, and that a View's source query draws none.
  It moves to parser 0.6.1 at release, as in 0.5.1.
playground\src\components\inspector\EntityInspector.vue
  The Source query section reads viewSourceQuery(), the first
  source_query: of the body. It used to join every SourceQueryItem.
playground\help\diagnostics-panel.md
  The warnings list gains source-query-in-settings and
  duplicate-source-query.
playground\help\inspector-pane.md     Source query line for Views.
playground\help\editor-pane.md        `Note` colored as a keyword only
                                      where it starts a note.
playground\help\when-parsing-fails.md
  "Stray comma" becomes "Commas between items" (accepted, except in
  indexes); new "A setting in a body"; "Reserved keyword as identifier"
  replaced by "Keywords as field names", since no quotes are needed now.
