xDBML -- 0.6.5, delta 4: VS Code 0.6.5, llms.txt and the MCP reference (internal definitions)
Base: origin/main f78776f (0.6.5, delta 3). Built 2026-10-03.

The VS Code extension and the TextMate grammar color `definitions` as a
block keyword before `{`. llms.txt, and the MCP reference generated from
it, describe internal definitions (spec 15.8) with three common mistakes.
This is the last delta of 0.6.5 before the release.

HOW TO APPLY
------------
Unzip the archive at the root of the clone (C:\Repos\Hackolade\xdbml-spec),
so that apply.cmd lands next to package.json and the other files land on
their own paths. Then, from cmd.exe at the repo root:

    apply.cmd

apply.cmd copies nothing. It checks that f78776f is in the history of HEAD
and that no commit since then touched the delivery's files, that every
file of the archive holds this delivery's content, and that the working
tree holds no other change. It then runs the gate (npm run check, mcp
type-check, the TextMate grammar test). It stops at the first failure and
does not commit. When it ends green it prints the git commands to commit
and push. No dependency change in the repo's packages; the .vsix is built.
