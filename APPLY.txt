xDBML -- v0.5 Delta 10a: fix ". was unexpected at this time" in the release tools
Base: Delta 10 applied and committed (Part 1 of its APPLY.txt).

WHAT HAPPENED
-------------
cmd.exe reads a whole `if ... ( ... )` block before running it, and inside a
block an unescaped `)` ends the block, even in the text of an echo. In
tools\release-preflight.cmd the wrangler check contains

    echo [FAIL] wrangler is not authenticated (or not installed).

The `)` after "installed" closed the block early, which left a lone "."
behind: ". was unexpected at this time." It fails even when wrangler is
fine, because the block is read whether or not its branch runs. So the
preflight stopped right after the npm checks: the wrangler, dev-tooling,
NODE_ENV, MCP-reference, test-suite and git checks never ran. Nothing was
changed or published.

The same pattern sat in two more preflight lines ("change(s)",
"problem(s)") and one line of tools\github-release.cmd. release.cmd has
none. Those scripts arrived after the 0.4.0 release, so this is their first
real run.

WHAT THIS CHANGES
-----------------
tools\release-preflight.cmd  three echo lines reworded without parentheses
tools\github-release.cmd     one echo line reworded without parentheses
tools\release.cmd            content unchanged; delivered with CRLF endings
.gitattributes (NEW)         *.cmd and *.bat get CRLF in the working tree
                             on every checkout. The repository stored the
                             three scripts with LF only, and with LF-only
                             lines cmd.exe can fail to find a GOTO label,
                             which release.cmd uses at every step. Git keeps
                             LF in the repository, so the commit shows only
                             the text changes above.
The three scripts in this package already have CRLF endings.

A scan of all three scripts finds no other unescaped parenthesis inside a
block (the `for /f ... in ('npm whoami')` group is real syntax, not text).

FILES
-----
  .gitattributes                 NEW
  tools\release-preflight.cmd    EDIT
  tools\github-release.cmd       EDIT
  tools\release.cmd              line endings only

APPLY (cmd.exe)
---------------
set REPO=C:\Repos\Hackolade\xdbml-spec
set DELTA=%CD%

copy /Y "%DELTA%\.gitattributes"                "%REPO%\.gitattributes"
copy /Y "%DELTA%\tools\release-preflight.cmd"   "%REPO%\tools\release-preflight.cmd"
copy /Y "%DELTA%\tools\github-release.cmd"      "%REPO%\tools\github-release.cmd"
copy /Y "%DELTA%\tools\release.cmd"             "%REPO%\tools\release.cmd"

cd /d C:\Repos\Hackolade\xdbml-spec
git add -A
git commit -m "release tools: no parentheses inside cmd blocks; CRLF for batch files"
