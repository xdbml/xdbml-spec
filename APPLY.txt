xDBML -- finish the 0.6.2 release with one command
Replaces xdbml-0.6.2-release-fix.zip; do not apply that one.

RUN
---
Unzip, then in cmd.exe:

    <unzipped folder>\apply.cmd

(If the repository is not at C:\Repos\Hackolade\xdbml-spec, pass its path:
 apply.cmd D:\path\to\xdbml-spec)

apply.cmd copies the two files below into the repository and runs
tools\release.cmd 0.6.2 from its root. Do not run release-preflight first:
the failed run left version bumps in the tree, and preflight requires a
clean one.

What the run does for 0.6.2:
  [1/6] parse 0.6.2 is on npm: skipped
  [2/6] render 0.6.2 is on npm: skipped
  [3/6] MCP server: install (retried until npm resolves 0.6.2), checks,
        tests, deploy
  [4/6] rendering API: install, type-check, deploy
  [5/6] prints the live dist-tags
  [6/6] git add, commit "release 0.6.2", push, tools\github-release.cmd 0.6.2

WHAT CHANGED
------------
tools\release.cmd
  Resumable: a package already on npm at the version is not installed,
  tested or published again, so after any failure the same command picks
  up where it stopped. npm install in steps 2 to 4 runs with
  --prefer-online and retries every 10 seconds for up to 3 minutes.
  New step 6 commits, pushes and runs github-release.cmd (itself already
  safe to rerun: an existing tag or release is kept or updated).
tools\RELEASE.md
  Step 6 and the resume behavior described.
