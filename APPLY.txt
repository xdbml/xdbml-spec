xDBML -- 0.6.2, delta 1 of 2: DBML forms, Container targets, name collisions
Base: main at 3dfbe34 (release 0.6.1). Apply before delta 2.

WHAT CHANGED
------------
parser\src\lexer.ts
  #3498DB (3 or 6 hex digits, unquoted, the DBML form) reads as the string
  '#3498DB'. Was a lex error, which rejected valid DBML (3.3).
parser\src\parser.ts
  text[] and varchar(20)[] keep their brackets in the type name (8.1).
  Was: the brackets read as an empty settings block and the field became
  text. Only brackets written with no space count; int [] is unchanged.
  Entity aliases (7.4): Table very_long as V, then Ref: V.id ... or
  [ref: > V.id]. Was unresolved-entity. A pass after parsing rewrites the
  endpoint to the entity name, so resolver, key rule and renderer all see
  the entity. An alias that repeats an entity or Container name, or that
  two entities declare, is left alone.
  SUPPORTED_XDBML_VERSION 0.6.2.
parser\src\name-resolver.ts
  name-collision (NEW): a Type and an Entity (or any two of Entity, View,
  Edge, Type, Enum, TablePartial) with one qualified name (15.5). Error
  from v0.6, warning before and without a version (DBML stays valid).
  Before, the two replaced each other in the symbol table.
parser\src\constraints.ts
  container-target-missing and container-target-not-in-project (NEW, 5.2
  rules 3 and 4): only for Containers written as such, only when the
  Project declares targets:, names compared through the 5.1 aliases
  (postgres = PostgreSQL). Error from v0.6, warning before. A Database
  with a target and no Project stays valid.
parser\test\run-tests.ts     11 tests (264 -> 275); the "newer version"
                              test now uses 0.6.3.
renderer\src\layout\layout.ts and
playground\src\components\inspector\FieldInspector.vue
  varchar(20)[] displays as written, not varchar[](20).
spec\v0.6.md                  3.3, 5.2, 7.4, 8.1, 15.5: one or two sentences each.
grammar\xDBML.g4              HEX_COLOR as a setting value; (LBRACK RBRACK)*
                              after scalarType.
grammar\test-cases.md         6 v0.6.2 cases.
playground\help\diagnostics-panel.md   the three new codes.
CHANGELOG.md                  v0.6.2 section (covers delta 2 as well).

Verified: parser 275, renderer 218+14+42, MCP 67, playground 52,
from-mongodb 24, vue-tsc, check:vsix, check:spec-links, docs:build.
