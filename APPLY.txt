WHAT CHANGED
------------
The cheatsheet that the MCP server's xdbml_reference tool returns, and that
xdbml.org/llms.txt serves, now tells an assistant what 0.5.1 accepts.

public\llms.txt
  The "Types:" paragraph gains three sentences: any other type name is
  valid and passes through, so a physical model uses its target's own
  types (number(10), varchar2(255), serial, bytea); a field names an Enum
  declared in a schema with its qualifier (status core.job_status); a name
  close to a declared Type or Enum draws possible-type-typo.
